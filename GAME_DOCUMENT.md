# Magical Byte Academy: The Enchanted Help Desk

**Course:** 273411 — Communicative English for Computer and Information Technology

**Target learners:** Beginner-to-intermediate university Computer Science and IT students.

**Learning objectives:** Greet clients professionally; ask diagnostic questions; give clear, polite troubleshooting instructions; explain technical risks; verify results; close a support conversation. Practice vocabulary including Wi-Fi, backup, syntax error, two-factor authentication, phishing, and outage.

**Story and role:** The player is a Magical IT Advisor in a cozy magical-school office. Luna, Celeste, Professor Ivy, Noah, Mochi, and Pixel bring nine support cases across three chapters. The player remains at the help desk rather than exploring the school as a student.

**Instructions:** Start a story, read the visitor’s problem, and respond in English. Type a response or use supported browser speech recognition, review the transcript, and confirm before sending. Read educational feedback, retry or use guided phrases, then continue. Five turns resolve each case. Use Continue to resume and the journal to practice completed cases.

**Core loop:** Visitor arrives → conversation → English response → explanatory feedback → diagnosis and troubleshooting → verification → professional closing → rewards → next visitor.

**Progress and motivation:** Magic Stars, XP, customer satisfaction, friendship hearts, five achievements, chapter unlocking, and automatic local browser saving. Practice replay does not award duplicate rewards.

**Technology and actual AI use:** HTML5, CSS3, vanilla JavaScript, original SVG pixel-style artwork, and LocalStorage. OpenAI Codex assisted with implementation, artwork, authored dialogue, and automated tests based on GAME_DESIGN.md. Runtime evaluation uses transparent authored intent rules, not a language model. No paid API, required API key, or backend is used. Browser speech services may process microphone audio remotely; the game does not store audio. It does not score pronunciation. Scores are gameplay feedback, not validated language proficiency measures.

**Evaluation and responsibility:** Automated unit and browser tests check progression, advice rejection, save restoration, all nine cases, and microphone UI states with a simulated recognition provider. Real microphone recognition quality and classroom learning effectiveness require human validation. No human playtesting results or team contributions have been invented. The team should review English accuracy, pedagogy, accessibility, and technical advice before presenting.
